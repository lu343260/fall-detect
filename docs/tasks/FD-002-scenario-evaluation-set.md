## 任务背景

当前只有少量人工测试和 60 张图片的 FP32/INT8 关键点输出对比，尚无完整跌倒识别指标。项目已知侧身弯腰误报，但缺少可复现样本和统一标签。

## 当前问题

- 没有覆盖主要正例、负例、遮挡、无人和恢复场景的标注集。
- 尚未统计准确率、精确率、召回率、F1、误报率、漏报率和告警/恢复延迟。
- 关键点输出误差不能替代跌倒检测准确率。

## 目标

建立不依赖具体模型文件的最小场景回归集、标签格式和统计口径，为状态机、输入尺寸和后端比较提供共同效果证据。

## 本次执行结果

已完成测试流程和数据规范：

- 新增 `docs/testing/scenario_evaluation_set.md`，定义场景分类、附加标签和版本号；
- 定义 `datasets/fall_eval_v1/` 的媒体、清单、标签、预测和报告目录规范；
- 更新 `docs/testing/test_record.md`，提供运行元数据、场景摘要和单样本明细模板；

- `evaluate_scenario_set.py` 读取 `datasets/fall_eval_v1/manifest.csv` 和 `labels/events.csv`；
