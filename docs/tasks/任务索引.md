## 任务状态定义

| 状态 | 定义 |
|---|---|
| `READY` | 任务已准备，可以执行 |
| `RUNNING` | 正在执行 |
| `BLOCKED` | 由于环境、依赖或外部条件无法执行 |
| `COMPLETED` | 任务完成 |
| `CANCELLED` | 任务取消 |

## 调度说明

- 优先推进 FD-002；它不依赖龙芯目标板，可先建立效果评估基础。
- 龙芯开发板和 LoongArch ONNX Runtime 环境恢复后，优先解锁 FD-001 与 FD-004。
- FD-003、FD-006 应在其依赖任务完成后再进入 `READY`。
- FD-005 分为两个阶段：PC 架构设计阶段无前置依赖；龙芯实际性能验证阶段依赖 FD-001/FD-004 的可用目标板和统一基线。
- FD-007 依赖 FD-002 的评估框架；Phase 1/2 可在 PC 先行，Phase 3 再进行目标板和 realtime 等价验证。
- FD-008 依赖 FD-002 的评估框架，并为 FD-007 提供固定数据集；结构完成后仍需补充真实样本和标签才能执行回归。
- 任务状态变更时，同时更新对应任务文件和本索引的“最后更新时间”。
