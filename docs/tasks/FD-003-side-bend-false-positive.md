## 任务背景

已有人工记录表明侧身弯腰可能误报跌倒。该问题直接影响规则状态机的可用性，但目前尚不能判断根因来自身体角度、宽高比、髋部轨迹、关键点置信度还是状态持续时间。

## 当前问题

- 误报样本数量和触发状态转换没有统一记录。
- 缺少与真实跌倒、坐下等相邻姿态的特征对照。
- 直接增加条件可能压制误报，却同时造成真实跌倒漏报。

## 目标

基于场景集回放定位误报触发链路，在保持正面/侧面跌倒检测能力的前提下降低侧身弯腰误报，并形成状态机回归证据。

## 修改范围

- 允许修改：`fall_detector.py` 及其部署副本中与状态机直接相关的最小逻辑；必要的调试输出和测试文档。
- 允许生成：特征轨迹、状态转换日志、回归指标报告。
- 不在范围：更换姿态模型、修改输入尺寸、重写推理后端或无数据依据地大幅调整阈值。

## 验收标准

- [ ] 至少复现并记录侧身弯腰误报的输入样本、触发帧和状态转换路径。
- [ ] 对身体角度、宽高比、髋部下降/速度、持续时间、关键点置信度完成对照分析。
- [ ] 侧身弯腰误报率较任务开始前下降，且正面/侧面跌倒样本未出现未经解释的召回下降。
- [ ] 状态机回归结果可由固定命令复现，并记录阈值变化和已知限制。
